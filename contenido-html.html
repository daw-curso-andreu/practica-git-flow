Modificar contenido HTML

Una de las cosas más útiles que puede hacer JavaScript es cambiar el contenido de un elemento HTML una vez que la página ya está cargada. Para ello primero localizamos el elemento (por ejemplo con document.getElementById()) y después modificamos su propiedad innerHTML, que representa todo el HTML que hay dentro de ese elemento.

Ejemplo 1 · ¿Qué puede hacer JavaScript?

JavaScript puede cambiar el contenido HTML.

<p id="demo">JavaScript puede cambiar el contenido HTML.</p>
<button type="button" id="btn-cambiar">¡Haz clic!</button>

// 1. Buscamos el botón por su id
const boton = document.getElementById('btn-cambiar');

// 2. Al hacer clic, sustituimos el contenido del párrafo
boton.addEventListener('click', () => {
  document.getElementById('demo').innerHTML = '¡Hola JavaScript!';
});

Explicación

  • document.getElementById('demo') devuelve el elemento cuyo atributo id vale demo.
  • addEventListener('click', ...) indica qué función se ejecuta cuando el usuario pulsa el botón.
  • Al asignar un nuevo valor a innerHTML se reemplaza todo el contenido anterior del párrafo.

Ejemplo 2 · Generar una lista a partir de un array

  • La lista está vacía.
const temas = ['El DOM', 'Seleccionar elementos', 'Eventos', 'innerHTML'];

document.getElementById('btn-lista').addEventListener('click', () => {
  // map() convierte cada tema en un <li> y join('') une todo en un único texto
  const html = temas.map((tema) => `<li>${tema}</li>`).join('');
  document.getElementById('lista-temas').innerHTML = html;
});

Explicación

innerHTML no solo admite texto: también interpreta etiquetas. Aquí construimos una cadena con varios elementos <li> usando template literals y la insertamos de una vez dentro de la lista, que el navegador vuelve a dibujar con los nuevos elementos.
