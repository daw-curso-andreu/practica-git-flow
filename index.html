Sobre el curso

Este curso está pensado para profesionales que ya conocen HTML y CSS y quieren dar el siguiente paso: usar JavaScript para interactuar con los elementos de una página. A lo largo de las distintas secciones veremos ejemplos sencillos, listos para probar en el navegador, en los que JavaScript lee y modifica el documento a través del DOM.

¿Qué aprenderás?

  • Modificar contenido HTML: cambiar el texto y el marcado de un elemento con innerHTML.
  • Modificar estilos CSS: alterar la apariencia de un elemento desde JavaScript con la propiedad style.
  • Modificar atributos HTML: cambiar valores como src, href o disabled.

Requisitos

Un navegador moderno y conocimientos básicos de HTML y CSS. No hace falta instalar nada.
