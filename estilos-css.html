Modificar estilos CSS

Cada elemento HTML tiene una propiedad style que permite cambiar sus estilos en línea desde JavaScript. La sintaxis es elemento.style.propiedad = 'valor', escribiendo la propiedad CSS en camelCase: font-size pasa a ser fontSize y background-color pasa a ser backgroundColor. Para cambios más grandes es mejor añadir o quitar clases con classList.

Ejemplo 1 · Cambiar el tamaño del texto

JavaScript puede cambiar el estilo de un elemento HTML.

// Seleccionamos el párrafo y el botón por su id
const texto = document.getElementById('texto-tamano');

document.getElementById('btn-tamano').addEventListener('click', () => {
  // font-size en CSS  →  fontSize en JavaScript
  texto.style.fontSize = '35px';
});

Explicación

Al pulsar el botón se asigna un valor a style.fontSize. El navegador lo aplica como si hubiéramos escrito style="font-size: 35px" en la etiqueta, por lo que tiene prioridad sobre las reglas del archivo CSS.

Ejemplo 2 · Elegir el color de fondo y del texto

Caja de ejemplo
const caja = document.getElementById('caja-color');

// El evento 'input' se lanza cada vez que el usuario mueve el selector de color
document.getElementById('color-fondo').addEventListener('input', (evento) => {
  caja.style.backgroundColor = evento.target.value;   // background-color
});

document.getElementById('color-texto').addEventListener('input', (evento) => {
  caja.style.color = evento.target.value;             // color
});

Explicación

evento.target.value contiene el color elegido en formato hexadecimal (por ejemplo #ff0000). Lo asignamos directamente a la propiedad de estilo correspondiente, así que la caja cambia en tiempo real mientras se elige el color.

Ejemplo 3 · Mostrar y ocultar un elemento

👋 ¡Hola! Puedes esconderme con JavaScript.

const aviso = document.getElementById('texto-visible');

// display = 'none' quita el elemento del flujo de la página
document.getElementById('btn-ocultar').addEventListener('click', () => {
  aviso.style.display = 'none';
});

// display = 'block' lo vuelve a mostrar
document.getElementById('btn-mostrar').addEventListener('click', () => {
  aviso.style.display = 'block';
});

Explicación

La propiedad display decide si un elemento se pinta o no. Con none desaparece y el resto del contenido ocupa su sitio; con block vuelve a aparecer.

Ejemplo 4 · Modo oscuro con classList

Esta zona cambia varios estilos a la vez al activar una clase CSS.

/* CSS: la clase .tema-oscuro agrupa todos los estilos del modo oscuro */
.tema-oscuro { background: #1e2a44; color: #f7df1e; }

// JS: toggle() añade la clase si no está y la quita si ya está
document.getElementById('btn-tema').addEventListener('click', () => {
  document.getElementById('zona-tema').classList.toggle('tema-oscuro');
});

Explicación

En lugar de cambiar propiedades una a una, definimos los estilos en una clase CSS y JavaScript solo se encarga de ponerla o quitarla. Es la forma más limpia de mantener separados el diseño (CSS) y el comportamiento (JavaScript).
