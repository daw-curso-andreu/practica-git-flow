Modificar atributos HTML

Los atributos (src, href, alt, disabled…) definen cómo se comporta y qué muestra cada elemento. Desde JavaScript podemos leerlos y cambiarlos de dos formas: accediendo directamente a la propiedad del elemento (img.src = '...') o con los métodos getAttribute() y setAttribute().

Ejemplo 1 · Encender y apagar una bombilla

const bombilla = document.getElementById('bombilla');

document.getElementById('btn-encender').addEventListener('click', () => {
  bombilla.src = 'img/bombilla-on.svg';   // cambiamos la imagen
  bombilla.alt = 'Bombilla encendida';    // y su texto alternativo
});

document.getElementById('btn-apagar').addEventListener('click', () => {
  bombilla.src = 'img/bombilla-off.svg';
  bombilla.alt = 'Bombilla apagada';
});

Explicación

La imagen es la misma etiqueta <img> todo el rato; lo único que cambia es el valor de su atributo src. Al modificarlo, el navegador descarga y muestra el nuevo archivo. Cambiamos también alt para que la descripción siga siendo correcta para lectores de pantalla.

Ejemplo 2 · Activar un campo de formulario

Valor actual de disabled: true

const campo = document.getElementById('campo-nombre');

document.getElementById('btn-activar').addEventListener('click', () => {
  campo.disabled = !campo.disabled;   // invertimos el atributo booleano
  campo.setAttribute('placeholder', campo.disabled ? 'Campo desactivado' : 'Escribe tu nombre');
  document.getElementById('estado-campo').innerHTML = campo.disabled;
});

Explicación

disabled es un atributo booleano: si está presente el campo no se puede usar. Con la propiedad campo.disabled lo añadimos o quitamos, y con setAttribute('placeholder', …) cambiamos el texto de ayuda según el estado.

Ejemplo 3 · Cambiar el destino de un enlace

Enlace: Documentación de referencia

Destino actual: https://developer.mozilla.org/es/

const enlace = document.getElementById('enlace');
const destinos = ['https://developer.mozilla.org/es/', 'https://www.w3schools.com/js/'];

document.getElementById('btn-enlace').addEventListener('click', () => {
  const actual = enlace.getAttribute('href');               // leemos el atributo
  const nuevo = actual === destinos[0] ? destinos[1] : destinos[0];
  enlace.setAttribute('href', nuevo);                       // y lo modificamos
  document.getElementById('destino').innerHTML = nuevo;
});

Explicación

getAttribute('href') devuelve el valor tal como está escrito en el HTML y setAttribute('href', nuevo) lo sustituye. Pasa el ratón por encima del enlace después de pulsar el botón para comprobar que la dirección ha cambiado.
